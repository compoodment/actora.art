# Space

[Space](https://actora.art/lab/space/) is an interactive 3D Newtonian sandbox. It includes selectable Solar System and Alpha Centauri simulations, hierarchy-aware body inspection, time controls, trails, camera tracking, and a free-camera mode.

The catalog includes stars, planets, dwarf planets, moons, exoplanets, and selected spacecraft. Some presentations use measured shapes and sourced maps; others use explicitly illustrative color surfaces where the available evidence does not support recovered global geography. Visual presentation is not used to invent orbital or physical measurements.

Signed-in visitors can keep bounded Space saves. A save is private account state, not a public profile feature. The experiment remains usable without asking Aurora to control it; Aurora's Space tools are read-only catalogue lookups and cannot change a simulation or a save.
